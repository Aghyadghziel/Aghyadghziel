### About

I build frontends, mostly with React and TypeScript. What I actually spend my time on is the part that usually gets skipped: how a page behaves on a slow connection, what a form says when it fails, and whether the thing genuinely works on a phone rather than just in a screenshot.

Design tools are part of how I work rather than someone else's job — I'm comfortable taking a project from a Figma file to something deployed. I build in both Arabic (RTL) and English.
